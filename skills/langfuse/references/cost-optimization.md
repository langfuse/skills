name: langfuse-cost-optimization
description: Optimize the cost of an LLM application or AI agent while preserving output quality.
---

Read the [cost optimization Academy page](https://langfuse.com/academy/experiments/cost-optimization) in full.

Always present the cost optimization opportunities in a table with these columns:

| Opportunity | Explanation and why it works | Estimated savings at analyzed volume | Implementation effort | Risk to output quality |
|---|---|---:|---|---|

For every opportunity, explain what would change and why that change should reduce cost. Link to the relevant [Academy guidance](https://langfuse.com/academy/experiments/cost-optimization) when it supports the explanation.

State the current cost and run volume used as the baseline. Estimate every opportunity's savings at that same volume. Label assumptions and use ranges when the available data does not support a precise estimate.
